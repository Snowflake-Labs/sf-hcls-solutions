# HCLS Field Targeting Platform

Pharmaceutical HCP field targeting platform for Zenixar (zenimab) plaque psoriasis,
demonstrating Cortex AI, Semantic View, and a Streamlit what-if scenario dashboard
for rules-engine-based call planning.

## Overview

| Item | Value |
|---|---|
| Database | SF_SOLUTIONS |
| Schema | FIELD_TARGETING |
| Industry | Healthcare & Life Sciences |
| Status | Done |

## Key Features

- **Cortex AI** — SENTIMENT and CLASSIFY_TEXT on call notes (Approach B: synthetic fallback included)
- **Semantic View** — `HCP_UNIVERSE_SV` for Cortex Analyst natural language queries
- **Streamlit Dashboard** — What-If Scenario, Competitive Forces, Recommendations tabs
- **HCP Microsegmentation** — Propensity scores, tiers (T1–T4/NT), KOL flags, channel preferences
- **9-Step Rules Engine** — Suppression, universe tiering, call planning (via skills)
- **Promotional Materials Analytics** — MATERIAL_EFFECTIVENESS view with sentiment and conversion metrics

## Data Model

```
Source (loaded via data.sql):
  HCP_MASTER_PROFILE    — 1,000 HCP profiles (Rheum/Derm/IM/FP)
  HCP_SUPPRESSION_FLAGS — Regulatory suppression flags per HCP
  BRAND_EXCLUSION_LIST  — Brand-specific exclusions (~30 rows)
  RX_WEEKLY_HCP         — Weekly TRx data (~2,640 rows, 4 weeks)
  HCP_MICROSEGMENT      — Propensity scores, tiers, KOL flags
  CALL_ACTIVITY         — CRM call records (~1,980 rows)

Reference (seeded in setup.sql):
  RESPONSE_CURVE        — Call-to-Rx lift curves by tier (40 rows)
  TERRITORY_DIM         — 50 territories across 5 regions
  SALES_REPS            — 50 field reps
  REP_TERRITORY_DIM     — Employee-territory assignments
  PROMO_MATERIALS_CATALOG — 24 promotional materials

Derived (generated by data.sql from CALL_ACTIVITY):
  CALL_NOTES_RAW        — Template-based call notes
  CALL_NOTES_ENRICHED   — Notes with sentiment scores + key signals
  CALL_MATERIAL_USAGE   — Material usage per call (~18% of calls)

Views:
  MATERIAL_EFFECTIVENESS — Material ROI: usage, sentiment, conversion rate

Rules Engine outputs (created by skills):
  RE_STEP1_ELIGIBLE_UNIVERSE — Post-suppression eligible universe
  RE_STEP2-4_*               — Universe tiering + refinement
  RE_STEP5-9_*               — Call planning + workload balancing
  SNAPSHOT_*                 — Baseline vs what-if comparisons
```
